# FPV-мастерская: APK + обновления без новых APK

## Один раз (настройка)
1. Создайте на github.com репозиторий (тип Public) и загрузите в него ВСЕ файлы из архива.
   Скрытую папку .github, если не перетаскивается: Add file → Create new file →
   имя `.github/workflows/build-apk.yml`, вставьте содержимое из архива.
2. Откройте файл `www/config.js` и замените ЛОГИН и РЕПО на свои в строке UPDATE_URL
   (адрес вида https://raw.githubusercontent.com/ЛОГИН/РЕПО/main/catalog.json). Commit.
3. Actions → Build APK → Run workflow. Через 5–10 минут APK появится в Releases (справа на главной
   странице репозитория) и в Artifacts. Скачайте app-debug.apk и установите на телефон.

## Обновление каталога (новые модели) — через админку
1. Откройте файл `admin.html` из репозитория в браузере (скачайте и откройте на компьютере или телефоне).
2. В блоке «Подключение к GitHub» укажите свой репозиторий и токен доступа (создаётся в
   GitHub → Settings → Developer settings → Personal access tokens, право на запись в репозиторий).
   Токен вводите только на своём устройстве и никому не показывайте.
3. Нажмите «Загрузить каталог», добавьте детали («Добавить деталь» → «Добавить в список»)
   и нажмите «🚀 Опубликовать обновление».
4. У пользователей при следующем запуске появится плашка «Доступно обновление каталога» и кнопка «Обновить».

## Обновление самого приложения (новый дизайн, функции)
Код приложения внутри APK, поэтому нужна новая сборка:
1. Измените `www/index.html` в репозитории, в `www/config.js` увеличьте APP_VERSION на 1.
2. Запустите Actions → Build APK. Новый APK появится в Releases.
3. В админке в блоке «Новая версия APK» укажите номер и описание и опубликуйте.
   Пользователи увидят плашку «Доступна новая версия» с кнопкой «Скачать».
   Установка поверх старой версии сохраняет их данные.

## ИИ-чат
Каждый пользователь вставляет свой ключ OpenRouter (openrouter.ai/keys) во вкладке «ИИ-чат».
Ключ хранится только на его телефоне.
